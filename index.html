Fonctionnalités

Ce que CampOrga fait pour vous

Trois fonctionnalités couvrent le parcours d’un camp, de sa page publique jusqu’à l’administration.

01

Une page publique pour chaque camp

Dès qu’un organisateur crée un camp, sa page est prête : dates, ville, âge minimum, places restantes et compte à rebours aux couleurs de la saison.

Les visiteurs partagent la page sur LinkedIn et posent leurs questions à l’assistant ou à la hotline.

02

Des inscriptions simples, suivies en direct

Un participant s’inscrit en trois étapes : son nom, son email, la confirmation. Aucun compte à créer.

L’organisateur retrouve les inscriptions, les présences et les messages reçus dans son tableau de bord.

03

Une administration sécurisée

Le super admin active les comptes, attribue les rôles et exporte une sauvegarde complète en SQL ou en CSV.

Les connexions sont protégées par un jeton signé et une double authentification par application ou par code.

Lancer en local

Essayez CampOrga sur votre machine

L’API, les bases de données et l’interface tournent chez vous, pas sur cette page.

  1. Prérequis. Installez Git, Node.js et Docker ou Podman.
  2. Clonez le projet depuis GitHub.
  3. Démarrez le backend : PostgreSQL, MongoDB et l’API.
  4. Démarrez l’interface, puis ouvrez-la dans votre navigateur.
Ouvrir l’application 
$ git clone https://github.com/BlackGhostMatrixx555/holbertonschool-portfolio.git
$ cd holbertonschool-portfolio
$ ./camporga.sh start      # API, PostgreSQL, MongoDB
$ ./camporga.sh frontend   # interface sur localhost:5173

À propos

Pourquoi nous avons construit CampOrga

Chaque été, des équipes organisent des camps pour faire découvrir le code à des jeunes. Chacune avançait de son côté : un tableur par camp, des inscriptions envoyées par email, aucune vue d’ensemble pour les directeurs.

Nous voulions qu’un organisateur puisse publier la page d’un camp en quelques minutes, et qu’un participant s’inscrive en trois étapes. Nous voulions aussi que les données restent entre les mains de l’organisation, avec des sauvegardes simples.

CampOrga est notre Portfolio Project à Holberton School. Nous l’avons conçu, développé et testé en équipe, de l’idée jusqu’à une version complète.
